The MCP research skill is now named `flashdata-mcp`. The separate `flashdata`
skill follows the standalone CLI workflow distributed at flashdata.dev, including
CLI v1.1.2 credential storage and Markdown content options. Task examples now ship
with complete-response readers and offline behavior tests.

This repository is the official home for portable Skills. The MCP repository
retains the MCP research skill and 15 task skills for client plugins; it excludes
the standalone CLI skill. Install each complete directory, including any bundled
scripts and references. Installation alone does not run a script or connect an account.
